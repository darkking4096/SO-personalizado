# Personalización SO

> Windows 11 Desktop Customization Hub — Centralize all personalization settings into a single visual interface.

## Features

- **Wallpaper Management** — Static wallpapers with scheduling and rotation
- **Taskbar Customization** — Position, transparency, color, visibility, size
- **Theme Control** — Light/Dark mode toggle + accent color picker
- **Keyboard Shortcuts Inventory** — Browse and search system shortcuts
- **Profile System** — Save, load, and switch between profiles instantly

## Getting Started

```bash
npm install
npm run dev          # Development mode
npm run build        # Production build
npm run build:exe    # Build Windows .exe
```
