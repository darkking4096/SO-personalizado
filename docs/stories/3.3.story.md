# Story 3.3: Create Profile Application Engine & Keyboard Shortcuts

## Summary
Implement profile application engine that atomically applies all settings in a profile. Also implement keyboard shortcuts for quick profile switching (Ctrl+Shift+1 through Ctrl+Shift+0 for top 10 profiles).

## Acceptance Criteria

- [x] Apply profile: Single click applies all bundled settings atomically
- [x] Progress indicator: Shows which settings are being applied
- [x] Rollback on error: Restore previous state if partial apply fails
- [x] Keyboard shortcuts: Ctrl+Shift+1..9, Ctrl+Shift+0 for 10 profiles
- [x] Shortcut registry in %APPDATA%/PersonalizacionSO/shortcuts.json
- [x] Shortcuts reorderable (drag/drop or UI)
- [x] Settings applied in correct order (wallpaper → taskbar → theme)
- [x] Error handling: Show which setting failed and why
- [x] TypeScript strict + ESLint compliant

## Technical Approach

**Services:**
- `src/services/profileManager.ts`:
  - `applyProfile(profileId: string)` → Atomically apply all settings
  - `applyProfileWithRollback(profileId: string, previousState: State)` → Apply with rollback
  - `validateProfileApplicable(profile: Profile)` → Check all settings valid

**Keyboard Handler:**
- `src/services/keyboardShortcutService.ts`:
  - `registerProfileShortcuts(profiles: Profile[])` → Register Ctrl+Shift+1..0
  - `unregisterProfileShortcuts()` → Cleanup
  - Uses Electron globalShortcut API

**Store:**
- Extend `src/stores/profileStore.ts`:
  - `isApplying: boolean`
  - `applyProgress: { current: string; progress: 0-100 }`
  - `lastAppliedProfile: string | null`
