# Story 2.5: Implement Icon Size & Spacing Customization

## Summary
Implement sliders for taskbar icon size (16px to 64px) and spacing between icons.

## Acceptance Criteria

- [x] Icon size slider: 16px to 64px with live preview indicators
- [x] Icon spacing slider: 0px to 20px
- [x] Both sliders apply via Registry
- [x] Changes apply instantly or within <500ms
- [x] All settings persist to profile
- [x] Reasonable presets (Compact, Normal, Comfortable)
- [x] Error handling for invalid values
- [x] TypeScript strict + ESLint compliant

## Technical Approach

**Components:**
- Update `src/components/TaskbarPanel.tsx` with two sliders

**Services:**
- Extend `src/services/registryManager.ts`:
  - `setIconSize(sizePixels: 16-64)`
  - `setIconSpacing(spacingPixels: 0-20)`
  - Read current values from Registry

**Store Updates:**
- `iconSize: number`
- `iconSpacing: number`
