# Story 2.5: Implement Icon Size & Spacing Customization

## Summary
Implement sliders for taskbar icon size (16px to 64px) and spacing between icons.

## Acceptance Criteria

- [ ] Icon size slider: 16px to 64px with live preview indicators
- [ ] Icon spacing slider: 0px to 20px
- [ ] Both sliders apply via Registry
- [ ] Changes apply instantly or within <500ms
- [ ] All settings persist to profile
- [ ] Reasonable presets (Compact, Normal, Comfortable)
- [ ] Error handling for invalid values
- [ ] TypeScript strict + ESLint compliant

## Technical Approach

**Components:**
- Update `src/components/TaskbarPanel.tsx` with two sliders

**Services:**
- Extend `src/services/registryManager.ts`:
  - `setIconSize(sizePixels: 16-64)`
  - `setIconSpacing(spacingPixels: 0-20)`
  - Read current values from Registry

**Store Updates:**
- `iconSize: number`
- `iconSpacing: number`
