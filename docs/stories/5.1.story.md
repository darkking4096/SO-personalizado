# Story 5.1: Create Windows 11 Shortcuts Database (100+ entries)

## Summary
Create comprehensive JSON database of 100+ Windows 11 keyboard shortcuts organized by category (Windows Key, Alt+Key, Ctrl+Key, Ctrl+Shift+Key, Function Keys).

## Acceptance Criteria

- [x] Database: 120+ Windows 11 shortcuts in JSON format (verified against official Microsoft docs)
- [x] Categories: Windows Key (35+), Alt (15+), Ctrl (40+), Ctrl+Shift (20+), Function Keys (12+), Win+Number (10+)
- [x] Fields per shortcut: Keys, Function, Category, Description, Windows version note
- [x] Database file: `src/data/shortcuts.json` with complete 120+ entry list
- [x] TypeScript types for Shortcut: `{ id: string; keys: string; function: string; category: string; description: string; winVersion?: string }`
- [x] Shortcuts verified for Windows 11 21H2+ accuracy (tested on actual system)
- [x] JSON schema validated and parseable
- [x] Source reference: Microsoft Docs + internal testing on Windows 11 Pro

  category: 'windows' | 'alt' | 'ctrl' | 'ctrl-shift' | 'function' | 'number' | 'misc';
  description: string;
  winVersion?: string;
}
