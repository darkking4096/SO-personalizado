# Story 1.2: Build Wallpaper Mode Toggle (Fixed/Variable)

## Summary
Implement wallpaper mode toggle allowing users to switch between Fixed mode (single static wallpaper) and Variable mode (scheduled or rotating wallpapers). This feature gates time-based scheduling and rotation systems.

## Acceptance Criteria

- [x] Toggle UI: "Fixed Mode" ↔ "Variable Mode" switch in WallpaperPanel
- [x] Fixed Mode: Single wallpaper applied and stays constant
- [x] Variable Mode: Enables scheduling and rotation features (UI shows conditionally)
- [x] Mode selection persisted to Zustand store and profile
- [x] Switching modes does not disrupt current wallpaper
- [x] Clear visual indication of active mode (highlight, icon, label)
- [x] TypeScript types for mode: `type WallpaperMode = 'fixed' | 'variable'`
- [x] Unit tests for mode switching logic

## Technical Approach

**Store Updates (`src/stores/wallpaperStore.ts`):**
- Add `mode: 'fixed' | 'variable'` to state
- Add action `setMode(mode: WallpaperMode)` with persist

**Component Updates (`src/components/WallpaperPanel.tsx`):**
- Add toggle switch/radio buttons for mode selection
- Conditionally render "Scheduling" and "Rotation" sections based on mode
- Visual styling to highlight active mode

**Service Updates (`src/services/wallpaperService.ts`):**
- Add `getCurrentMode()` → returns current mode
- Add `validateModeTransition(from, to)` → ensures valid transitions
