# Story 3.4: Add Default Profile & Startup Auto-Apply

## Summary
Implement default profile selection and automatic application on app startup. Users can skip auto-apply by holding Shift during launch.

## Acceptance Criteria

- [ ] UI: Radio button or dropdown to set default profile
- [ ] Startup: Auto-apply default profile on app launch (unless Shift held)
- [ ] Hold Shift during launch: Skip auto-apply
- [ ] Default profile setting persisted to config
- [ ] Clear visual feedback during auto-apply
- [ ] Error handling: If default profile apply fails, show warning
- [ ] No default profile: App starts without applying anything
- [ ] TypeScript strict + ESLint compliant

## Technical Approach

**Components:**
- Update `src/components/ProfileManager.tsx` with "Set as Default" button or radio

**Services:**
- Extend `src/services/profileManager.ts`:
  - `getDefaultProfile()` → Read default profile ID
  - `setDefaultProfile(profileId: string)` → Set default
  - `applyDefaultProfileOnStartup()` → Called from main process on launch

**Electron Main Process:**
- Detect Shift key press during launch (using native keyboard detection)
- Call `applyDefaultProfileOnStartup()` if Shift not held
- Show startup loading state in renderer

**Store:**
- `defaultProfileId: string | null`
- `isAutoApplyingOnStartup: boolean`
