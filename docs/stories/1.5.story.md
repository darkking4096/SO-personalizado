# Story 1.5: Add Rotation UI & Presets

## Summary
Implement user-friendly rotation UI with preset configurations for common use cases (Work, Gaming, Relaxation, Nature) to reduce configuration friction.

## Acceptance Criteria

- [x] RotationConfigPanel integrated into WallpaperPanel
- [x] Four presets available: Work (30min), Gaming (10min), Relaxation (1hr), Nature (2hr)
- [x] Presets include curated image pool references
- [x] Users can create custom presets from current config
- [x] Presets saved/loaded from JSON in %APPDATA%
- [x] Preset UI: Buttons or cards for quick selection
- [x] Custom preset creation: Save current config with name
- [x] Delete preset functionality
- [x] UI shows active preset name
- [x] Presets persist in profile
- [x] TypeScript types for Preset: `{ name: string; config: RotationConfig; createdAt: Date }`
- [x] Unit tests for preset CRUD

## Technical Approach

**Components:**
- Update `src/components/WallpaperPanel.tsx` to include preset section
- Add preset selector buttons/cards
- Add "Save Preset" dialog

**Services:**
- `src/services/wallpaperService.ts`:
  - `getPresets()` → Load all presets
  - `savePreset(name: string, config: RotationConfig)` → Create preset
  - `deletePreset(presetId: string)` → Remove preset
  - `applyPreset(presetId: string)` → Apply preset config to current rotation

**Store (`src/stores/wallpaperStore.ts`):**
- `presets: Preset[]`
- `activePresetId: string | null`

**Presets Data (`src/data/wallpaperPresets.ts`):**
