# Story 4.2: Build Accent Color Picker & Preview

## Summary
Implement accent color picker allowing users to customize Windows 11 accent color and preview it in real-time within the application.

## Acceptance Criteria

- [ ] Color picker UI: Visual picker + hex input field
- [ ] Preset color palette: Windows 11 defaults + suggestions
- [ ] Live preview: Accent color changes visible in app UI
- [ ] Apply accent to: Windows Start Menu, Taskbar, App buttons/links
- [ ] Color persisted to Windows Registry and profile
- [ ] Error handling for invalid color values
- [ ] TypeScript strict + ESLint compliant

## Technical Approach

**Components:**
- Update `src/components/ThemePanel.tsx` with color picker section
- `src/components/ColorPicker.tsx` — Color picker widget (custom or react-color library)
- `src/components/ColorPreset.tsx` — Preset color buttons

**Services:**
- `src/services/themeService.ts`:
  - `setAccentColor(hexColor: string)` → Apply to Windows + App
  - `getAccentColor()` → Read current accent
  - `validateColor(hexColor: string)` → Validate hex format

**Presets:**
- Windows 11 default colors: Blue, Purple, Red, Pink, Green, Cyan, etc.
- Store hex values in `src/data/colorPresets.ts`

**Store (`src/stores/themeStore.ts`):**
- `accentColor: string` (hex format #RRGGBB)
- `previewColor: string` (for live preview before apply)

## Technical Notes

1. **Color Validation:** Accept #RGB, #RRGGBB formats; normalize to #RRGGBB
2. **Preview:** Apply color to CSS variables in real-time before Registry write
3. **Registry Path:** `HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Explorer\Accent`
4. **Live Update:** Use CSS custom properties for instant preview
