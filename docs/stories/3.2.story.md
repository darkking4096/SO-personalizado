# Story 3.2: Build Profile Manager UI (Create, Edit, Delete)

## Summary
Implement Profile Manager panel allowing users to create, edit, delete, and manage profiles visually.

## Acceptance Criteria

- [ ] Profile list view: Displays all profiles with created/updated dates
- [ ] Create new profile: Dialog with name input + settings selector checkboxes
- [ ] Edit profile: Modify name and settings inclusion
- [ ] Delete profile: Confirmation dialog before deletion
- [ ] Profile list shows profile count, storage size
- [ ] Search/filter profiles by name
- [ ] Icons for actions: Create (+), Edit (pencil), Delete (trash)
- [ ] Error messages clear and helpful
- [ ] TypeScript strict + ESLint compliant

## Technical Approach

**Components:**
- `src/components/ProfileManager.tsx` — Main profile panel
- `src/components/ProfileList.tsx` — Profile list view
- `src/components/CreateProfileDialog.tsx` — Create dialog
- `src/components/EditProfileDialog.tsx` — Edit dialog

**Store:**
- Extend `src/stores/profileStore.ts` with actions:
  - `addProfile(profile: Profile)`
  - `updateProfile(id: string, changes: Partial<Profile>)`
  - `deleteProfile(id: string)`
