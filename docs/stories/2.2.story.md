# Story 2.2: Add Taskbar Transparency & Color Picker

## Summary
Implement taskbar transparency slider (0-100%) and color picker for taskbar background customization via Windows Registry.

## Acceptance Criteria

- [x] Transparency slider: 0% (opaque) to 100% (transparent)
- [x] Color picker: Visual + hex input
- [x] Live preview of transparency/color before apply
- [x] Apply changes to Registry: `HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Explorer\Advanced`
- [x] Changes apply instantly or within <500ms
- [x] Both settings persist to profile
- [x] Error handling for permission issues
- [x] TypeScript strict + ESLint compliant

## Technical Approach

**Components:**
- Update `src/components/TaskbarPanel.tsx` with transparency slider and color picker
- `src/components/ColorPicker.tsx` — Custom or library-based (react-color)

**Services:**
- Extend `src/services/registryManager.ts`:
  - `setTaskbarTransparency(value: 0-100)`
  - `setTaskbarColor(hexColor: string)`
  - `getTaskbarTransparency()` → Read current value
  - `getTaskbarColor()` → Read current color

**Store Updates:**
- `transparency: number`
- `backgroundColor: string`
- `previewColor: string` (for live preview)
