## Technical Approach

**Runtime Stack:**
- Electron 28+ (main + renderer processes)
- React 18 + TypeScript for UI layer
- Vite as build tool and dev server
- Tailwind CSS for styling with dark mode support
- Zustand for state management
- node-ffi and windows-registry for Windows API integration

**Project Structure:**
```
Personalização SO/
├── packages/
│   ├── main/                    # Electron main process
│   │   └── src/
│   │       ├── main.ts          # Entry point
│   │       ├── preload.ts       # IPC bridge
│   │       └── ipc/
│   │           ├── handlers.ts
│   │           └── channels.ts
│   └── renderer/                # React app
│       └── src/
│           ├── App.tsx          # Root component
│           ├── components/      # UI components
│           ├── stores/          # Zustand stores
│           ├── services/        # Service layer (stubs)
│           ├── styles/          # Tailwind config
│           └── types/           # TypeScript interfaces
├── src/                         # Shared code
│   ├── services/                # Service stubs
│   │   ├── wallpaperService.ts
│   │   ├── registryManager.ts
│   │   ├── profileManager.ts
│   │   ├── themeService.ts
│   │   └── keyboardService.ts
│   ├── types/                   # Shared types
│   └── utils/                   # Utilities
├── tests/                       # Test directory
├── docs/                        # Documentation
│   ├── ARCHITECTURE.md
│   └── SETUP.md
├── .github/
│   └── workflows/
│       └── build.yml            # CI/CD pipeline
├── package.json
├── tsconfig.json
├── tailwind.config.js
├── vite.config.ts
└── electron.vite.config.ts
```

**Windows API Integration:**
- `node-ffi` for direct Windows API calls (SystemParametersInfo)
- `windows-registry` for Registry operations (HKEY_CURRENT_USER)
- Service stubs: Ready to accept implementations from EPIC-1, EPIC-2, etc.

## Implementation Notes

1. **Project Initialization:**
   - Use `electron-vite` starter to scaffold Electron + Vite + React + TypeScript
   - Alternative: Create from scratch using official Electron + Vite + React templates

2. **State Management Setup:**
   - Install `zustand` and create initial app store
   - Plan store structure for: wallpaper, taskbar, theme, shortcuts, profiles

3. **Styling Configuration:**
   - Install `tailwindcss` and dependencies
   - Configure dark mode (class or media query strategy)
   - Create Tailwind config for reusable color palette

4. **Service Layer Stubs:**
   - Create placeholder TypeScript interfaces for all services
   - Add JSDoc comments explaining expected functionality
   - Ensure type safety from the start

5. **Windows API Integration:**
   - Install `node-ffi` and `windows-registry`
   - Create service stubs that will be implemented in later epics
   - Add error handling stubs (graceful fallback for non-admin users)

6. **CI/CD Setup:**
   - Create `.github/workflows/build.yml`
   - Configure for: lint → typecheck → build → test
   - Ensure builds produce signed .exe (placeholder for later)

7. **Git & Repository:**
   - Initialize git repository
   - Create `.gitignore` for Electron/Node projects
   - Push initial commit with project structure
   - Verify CI/CD pipeline runs successfully
