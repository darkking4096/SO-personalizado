# Story 4.1: Implement Light/Dark Theme Toggle

## Summary
Implement Light/Dark theme toggle for application UI with Tailwind CSS dark mode. Also apply Windows 11 system theme setting.

## Acceptance Criteria

- [ ] Toggle switch: Light ↔ Dark theme in UI
- [ ] Theme applies to: Application UI (React components)
- [ ] System theme control: Set Windows 11 Light/Dark mode via Registry
- [ ] Apply instantly without restart
- [ ] Theme setting persisted to profile and config
- [ ] Tailwind dark mode configured (class strategy: `<html class="dark">`)
- [ ] All app colors change correctly with theme
- [ ] TypeScript strict + ESLint compliant

## Technical Approach

**Components:**
- `src/components/ThemePanel.tsx` — Theme toggle and color picker container

**Services:**
- `src/services/themeService.ts`:
  - `setAppTheme(theme: 'light' | 'dark')` → Apply to React
  - `setWindowsTheme(theme: 'light' | 'dark')` → Apply to Registry
  - `getCurrentTheme()` → Read current theme
  - `detectSystemTheme()` → Read Windows theme preference

**Store (`src/stores/themeStore.ts`):**
- `appTheme: 'light' | 'dark'`
- `windowsTheme: 'light' | 'dark'`
- `syncWithSystem: boolean`

**Styling:**
- Update `tailwind.config.js` to use class dark mode strategy
- Create CSS variables in `src/styles/theme.ts` for consistent coloring
