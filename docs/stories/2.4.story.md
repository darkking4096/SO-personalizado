# Story 2.4: Create Taskbar Item Visibility Manager

## Summary
Implement checkboxes to toggle visibility of taskbar elements: Clock, Calendar, Weather, System Tray, Copilot, Search, Task View, Virtual Desktops.

## Acceptance Criteria

- [ ] Checkboxes for 8 taskbar elements (Clock, Calendar, Weather, System Tray, Copilot, Search, Task View, Virtual Desktops)
- [ ] Each checkbox controls Registry entry for that element
- [ ] Changes apply instantly or within <500ms
- [ ] All settings persist to profile
- [ ] Error handling for permission issues
- [ ] UI shows current state on app load
- [ ] TypeScript strict + ESLint compliant

## Technical Approach

**Components:**
- Update `src/components/TaskbarPanel.tsx` with visibility checklist

**Services:**
- Extend `src/services/registryManager.ts`:
  - `setItemVisibility(itemName: string, visible: boolean)`
  - `getItemVisibility(itemName: string)` → Read state
  - Map items to Registry paths

**Store Updates:**
- `visibleItems: Record<string, boolean>` — e.g. `{ clock: true, copilot: false, ... }`

## Registry Paths

| Item | Registry Path | Value |
|------|---------------|-------|
| Clock | `...Explorer\Advanced` | `ShowSecondsInSystemClock` |
| System Tray | `...Explorer\Advanced` | `ShowSystemTray` |
| Search | `...Explorer\Advanced` | `TaskbarSearchBoxMode` |
| Task View | `...Explorer\Advanced` | `ShowTaskViewButton` |
| Virtual Desktops | `...Explorer\Advanced` | `VirtualDesktopTaskbarButton` |
| Copilot | `...Explorer\Advanced` | `ShowCopilotButton` |
