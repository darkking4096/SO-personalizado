# Story 1.1: Implement Static Wallpaper Selection & Application

## Summary
Implement core wallpaper selection functionality allowing users to browse, preview, and apply static wallpapers (JPEG, PNG, BMP, WEBP) to all monitors or specific monitors.

## Acceptance Criteria

- [x] User can browse file system and select image files (JPEG, PNG, BMP, WEBP)
- [x] Live preview of selected wallpaper before applying
- [x] Apply wallpaper to: All Monitors or Specific Monitor (dropdown)
- [x] Wallpaper applies successfully using Windows API (SystemParametersInfo)
- [x] Selected wallpaper path persisted to Zustand store
- [x] Error handling: Display user-friendly message if apply fails
- [x] Performance: Image loading <500ms, apply <1s
- [x] UI is intuitive: Browse button → Preview → Apply button
- [x] Works on Windows 11 Pro and Home editions
- [x] All code passes TypeScript strict mode and ESLint

## Technical Approach

**Components:**
- `src/components/WallpaperPanel.tsx` — Main UI panel with file browser, preview, apply button
- `src/components/MonitorSelector.tsx` — Dropdown to select all/specific monitor

**Services:**
- `src/services/wallpaperService.ts`:
  - `selectWallpaper(filePath: string)` — Load image file
  - `applyWallpaper(filePath: string, monitorId?: string)` — Apply via SystemParametersInfo
  - `getAvailableMonitors()` — Query connected monitors
  - Error handling with graceful fallback

**State (Zustand):**
- `src/stores/wallpaperStore.ts`:
  - `currentWallpaper: { path: string; monitorId?: string }`
  - `previewImage: string` (base64 or file URL)
  - `availableMonitors: Monitor[]`
  - `isApplying: boolean`
  - `error: string | null`

**Windows API:**
- `SystemParametersInfo()` for wallpaper application
- `EnumDisplayMonitors()` to list available monitors (via node-ffi)

## Technical Notes

1. **File Browser:** Use Electron's `dialog.showOpenDialog()` for native file picker
2. **Preview:** Load image as data URL for preview display (sharp → canvas)
3. **Monitor Detection:** Query Windows via `EnumDisplayMonitors()` to populate dropdown
4. **Apply Logic:** Call `SystemParametersInfo(SPI_SETDESKWALLPAPER, 0, filePath, SPIF_UPDATEINIFILE | SPIF_SENDCHANGE)`
5. **Error Handling:** Catch and display errors (missing file, permission denied, API failure)
