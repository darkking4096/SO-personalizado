# Story 2.3: Build Taskbar Size & Format Controls

## Summary
Implement taskbar size presets (Small, Default, Large) and custom size slider for height/width control.

## Acceptance Criteria

- [x] Size presets: Small, Default, Large buttons
- [x] Custom size slider: Allows fine-tuning
- [x] Auto-hide toggle: Checkbox to hide taskbar when not in use
- [x] Apply via Registry: `HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Explorer\Advanced`
- [x] Changes apply instantly or within <500ms
- [x] Settings persist to profile (via Zustand store)
- [x] Error handling for invalid values (validation in registry methods)
- [x] TypeScript strict + ESLint compliant (all checks passing)

## Technical Approach

**Components:**
- Update `src/components/TaskbarPanel.tsx` with preset buttons and size slider
- `src/components/SizeSelector.tsx` — Preset buttons + custom slider

**Services:**
- Extend `src/services/registryManager.ts`:
  - `setTaskbarSize(sizePreset: 'small' | 'default' | 'large' | number)`
  - `setAutoHide(enabled: boolean)`
  - `getTaskbarSize()` → Read current size
  - `getAutoHideStatus()` → Read current status

**Store Updates:**
- `size: 'small' | 'default' | 'large' | number`
- `autoHide: boolean`
