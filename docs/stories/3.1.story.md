# Story 3.1: Implement Profile Creation & Storage (JSON)

## Summary
Implement profile creation and JSON-based persistence in %APPDATA%/PersonalizacionSO/profiles/. Profiles bundle settings from Wallpaper, Taskbar, Theme, and Shortcuts.

## Acceptance Criteria

- [ ] Profiles stored as JSON files in %APPDATA%/PersonalizacionSO/profiles/{profileName}.json
- [ ] Profile JSON schema includes: wallpaper, taskbar, theme, shortcuts settings
- [ ] Create new profile from current settings
- [ ] Save profile: Choose name, select which settings to include (checkboxes)
- [ ] Profile validation: Ensure all referenced images/settings exist
- [ ] Error handling: Handle file system errors, permission issues
- [ ] TypeScript types for Profile: `{ name: string; settings: Settings; createdAt: Date; updatedAt: Date }`
- [ ] Atomic file operations: backup before overwrite

## Technical Approach

**Services:**
- `src/services/profileManager.ts`:
  - `createProfile(name: string, selectedSettings: SettingsFilter)` → Create new profile
  - `saveProfile(profile: Profile)` → Write to JSON
  - `loadProfile(name: string)` → Read from JSON
  - `getAllProfiles()` → List all profiles
  - `validateProfile(profile: Profile)` → Check all refs exist

**Store (`src/stores/profileStore.ts`):**
- `profiles: Profile[]`
- `currentProfile: Profile | null`

**Types (`src/types/profile.ts`):**
```typescript
interface Profile {
  id: string;
  name: string;
  settings: {
    wallpaper?: WallpaperSettings;
    taskbar?: TaskbarSettings;
    theme?: ThemeSettings;
    shortcuts?: ShortcutsSettings;
  };
  createdAt: Date;
  updatedAt: Date;
}
```
