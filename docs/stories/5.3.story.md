# Story 5.3: Build Favorites/Pinning System

## Summary
Implement favorites/pinning system allowing users to star/pin frequently used shortcuts. Pinned shortcuts appear at top of list and persist in profile.

## Acceptance Criteria

- [ ] Star icon: Click to pin/unpin shortcut
- [ ] Pinned section: Pinned shortcuts displayed at top of list
- [ ] Visual distinction: Pinned shortcuts highlighted or separated
- [ ] Persistence: Favorites saved to profile in JSON
- [ ] Unlimited favorites: Users can pin as many as desired
- [ ] Remove favorite: Click star again to unpin
- [ ] Favorites persist across app restarts
- [ ] TypeScript strict + ESLint compliant

## Technical Approach

**Components:**
- Update `src/components/ShortcutList.tsx` with star icons
- `src/components/PinnedSection.tsx` — Pinned shortcuts section (optional)

**Services:**
- Extend `src/services/shortcutSearchService.ts`:
  - `pinShortcut(shortcutId: string)` → Add to favorites
  - `unpinShortcut(shortcutId: string)` → Remove from favorites
  - `getPinnedShortcuts()` → Get all pinned
  - `isPinned(shortcutId: string)` → Check if pinned

**Store (`src/stores/shortcutsStore.ts`):**
- `pinnedShortcutIds: Set<string>`
- Actions: `togglePin(id: string)`, `setPinned(ids: string[])`

**Profile Integration:**
- Include pinned shortcuts in profile serialization
- Restore pinned shortcuts when profile loads
