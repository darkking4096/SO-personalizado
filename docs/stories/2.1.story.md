# Story 2.1: Implement Taskbar Position Control (Bottom/Left/Right/Top)

## Summary
Implement Windows Registry-based taskbar position control allowing users to move taskbar to Bottom, Left, Right, or Top screen edges.

## Acceptance Criteria

- [ ] UI: Radio buttons or buttons for 4 positions (Bottom/Left/Right/Top)
- [ ] Registry write to `HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Explorer\StuckRects3`
- [ ] Position changes apply immediately (or within <500ms)
- [ ] Explorer process restart if necessary for changes to take effect
- [ ] Error handling: Admin rights required; show graceful message if denied
- [ ] Current position read from Registry on app startup
- [ ] Position persisted to Zustand store and profile
- [ ] Works on Windows 11 Pro and Home editions
- [ ] All code TypeScript strict + ESLint compliant

## Technical Approach

**Components:**
- `src/components/TaskbarPanel.tsx` — Main taskbar customization panel
- `src/components/PositionSelector.tsx` — Position radio buttons/buttons

**Services:**
- `src/services/registryManager.ts`:
  - `getTaskbarPosition()` → Read from Registry
  - `setTaskbarPosition(position: 'bottom' | 'left' | 'right' | 'top')` → Write to Registry
  - `restartExplorer()` → Restart Explorer if needed

**Types:**
```typescript
type TaskbarPosition = 'bottom' | 'left' | 'right' | 'top';
```

**Store (`src/stores/taskbarStore.ts`):**
- `position: TaskbarPosition`
- `isApplying: boolean`
- `error: string | null`

## Technical Notes

1. **Registry Path:** `HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Explorer\StuckRects3`
2. **Value to Modify:** Binary data encoding position (requires careful byte manipulation)
3. **Explorer Restart:** May need `taskkill /f /im explorer.exe && start explorer.exe`
4. **UAC Elevation:** Handle gracefully if user lacks admin rights
