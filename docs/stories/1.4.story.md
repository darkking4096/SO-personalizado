# Story 1.4: Implement Dynamic Wallpaper Rotation Engine

## Summary
Implement wallpaper rotation engine supporting multiple rotation modes: Sequential (cycle through images in order), Random (pick random image), and Random Weighted (probability-based selection). Users can configure rotation interval and mode.

## Acceptance Criteria

- [ ] Three rotation modes implemented: Sequential, Random, Random Weighted
- [ ] Rotation interval configurable: 5 minutes to 24 hours
- [ ] Rotation engine applies wallpapers in background
- [ ] Sequential mode: Cycles through images in defined order without repetition until restart
- [ ] Random mode: Each transition picks random image (may repeat)
- [ ] Random Weighted mode: Images have weight/probability; higher weight = more likely
- [ ] Image list: User selects folder or multiple files for rotation pool
- [ ] Rotation persisted to store and profile
- [ ] Error handling: Skip missing images, continue with available ones
- [ ] Performance: Rotation transitions smooth (<1s apply time)
- [ ] TypeScript types for rotation config
- [ ] Unit tests for rotation logic

## Technical Approach

**Components:**
- `src/components/RotationConfigPanel.tsx` — Mode selector, interval picker, image pool manager

**Services:**
- `src/services/wallpaperService.ts`:
  - `startRotation(config: RotationConfig)` → Begin rotation with specified mode
  - `stopRotation()` → Stop active rotation
  - `getNextRotationImage(mode: RotationMode)` → Get next image based on mode
  - `rotateImage()` → Apply next image in sequence

**Types (`src/types/wallpaper.ts`):**
```typescript
type RotationMode = 'sequential' | 'random' | 'weighted';
interface RotationConfig {
  mode: RotationMode;
  intervalMinutes: number;
  imagePool: string[];
  weights?: Record<string, number>; // For weighted mode
}
```

**Store (`src/stores/wallpaperStore.ts`):**
- `rotationConfig: RotationConfig | null`
- `rotationIndex: number` (for sequential mode)
- `isRotating: boolean`

## Technical Notes

1. **Sequential Mode:** Maintain pointer to current image; increment on each rotation
2. **Random Mode:** Use `Math.random()` to select from pool
3. **Weighted Mode:** Normalize weights, generate CDF, use weighted random selection
4. **Interval:** Use `setInterval()` to trigger rotation checks at configured interval
5. **Image Pool:** Store as array of file paths; validate on every rotation
